# Changelog

## 1.0.1

- Removed the global `+`, `-`, `=`, and `0` zoom shortcuts so they cannot interfere with Antigravity text input.
- Scoped page-navigation keys to the PDF viewer.
- Added automatic refresh after an open PDF is regenerated or replaced.
- Added localized visual hover tooltips to every toolbar icon.
- Moved the thumbnail-sidebar toggle to the left side of the toolbar.
- Added a retry for the short launchd unload/reload race during updates.

## 1.0.0

- Initial release with PDF.js rendering, trackpad zoom, reset view, thumbnails, full preview, localization, and large-file Range streaming.
